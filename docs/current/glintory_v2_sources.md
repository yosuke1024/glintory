## PR TIMES 運用ルール(必須)

各プレスリリースの著作権は発表企業に帰属するため、以下を実装で強制する:

1. Glintory が保持するのは タイトル / 短い抜粋 / リンク / 正規化本文(抽出処理のための一時保持、90日で削除)まで。
2. `evidence_span` は最大300文字の逐語引用に制限(仕様書 §6.1)し、引用の範囲を超えない。
3. Loka 側の遵守事項(供給契約 §2)として、**全文翻訳・転載を禁止**し、事実ベースの再構成記事+出典リンクの形式に限定する。
4. 全件フィードは流量が多いため(日数百件)、収集段階で topic 関連キーワードによる事前フィルタを行い、抽出バジェットを守る。

## manifest への反映

検証合格した initial 源を `config/sources.json`(仕様書 §4 の形式)として登録する。`license_note` には本リストのライセンス要点を転記する。フィード URL は検証ワークフローが返した最終 URL(リダイレクト解決後)を正とする。
